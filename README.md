## 🗂️ How This Repo Works

- Each track has its own folder with a `README.md` containing all session notes for that domain.
- Every session follows the same format: **Topics Covered → Resources → Practice Questions → Homework**.
- Missed a class? Head to the relevant track's README, find the session by date/topic, and catch up using the notes + resources.
- Questions? Drop them in the club's Discord/WhatsApp group or open an issue in this repo.
